vCenter, Supervisor & VKS Upgrade Planner

Plan a compatible upgrade across vCenter, vSphere Supervisor, VKS and your Kubernetes Releases.

How this works

Tell us the versions you run today and where you want to land. This planner computes an ordered, compatibility-checked plan across all four layers, grouped into stages, with the reason for every step.

  • Every version list comes from the generated Broadcom interoperability matrix — nothing is hardcoded.
  • The plan never proposes an uncompatible hop: Supervisor/Kubernetes Releases move one Kubernetes minor at a time.
  • If upgrade paths for both 8.x and 9.x are available, the planner displays them side-by-side instead of automatically selecting one for you.
  • Use the VCF Upgrade Planner if you want to include NSX, ESX, VCF Operations, VCF Automation.
Anything you leave blank on the target side is planned for you when reaching a target you did specify requires moving it. Incompatible options are greyed out rather than hidden. Required fields are marked as you choose versions, and a note explains any selection cleared by a filter.
